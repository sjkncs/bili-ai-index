## Data source / method / limits

**Data source**: `seasons_archives_list` for the episode list; `x/web-interface/view`
per video for its **`desc`** field.

**Method**: this source has **no description template**. `speaker`/`affiliation` come
ONLY from a guest-intro block and only when it starts with `Name, Affiliation` or
`Name Affiliation`; results are validated and demoted to affiliation-only when the
"name" looks wrong. **The title is never split** -- this source's titles mix several
styles and splitting them produced wrong data.

**Limits**: only part of the entries carry a guest-intro block, so this is **not a
complete speaker roster**; panel entries list several people and are NOT split per person;
`full_title` is empty for this source.
